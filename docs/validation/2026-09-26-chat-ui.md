## Open acceptance limits

- The shadow strategy changed from the proposed custom-depth prototype to
  bounded vector projection and DEM ray sampling. Live district screenshots
  show terrain and building context, but do not prove exact shadow alignment,
  neighboring wall occlusion, tile-edge continuity, distant relief shadows or
  sustained performance on other GPUs. See [decision 0004](../decisions/0004-map-first-chat-scene.md).
- The server persists a bounded FIFO for chat turns, including idempotent
  retries and withdrawal before execution. Concurrent changes to maps, plans,
  and other non-turn actions still return a stale revision for user review.
- Offline parsing covers common place, coordinate, product and year phrases;
  the optional model parser handles broader language when configured. The UI
  has not been user-tested for all multi-intent and correction phrasings.
- A terrain tile failure and every appearance at both globe and district
  zoom have not yet been visually inspected. External map services have no
  local SLA. Source-scope outlines remain documentary, not point eligibility.
- Chart drag, resize and keyboard operations are implemented; automated browser
  accessibility coverage is limited to the controls and fallback table rather
  than a full assistive-technology audit.

## Chat dock, navigation and markdown (2026-09-27)

  and Start over, the current question card with its options, status and the
  input. Back (`POST /v1/chat/sessions/{id}/back`) restores the state before
