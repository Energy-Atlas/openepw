# PVGIS v5_3 TMY map context

Reviewed 2026-09-24 for the local multi-product availability map on `feature/data-avail`. This is a bounded documentation follow-up. No Stage 1 collection was rerun, and no new TMY request or hourly data was acquired.

The [JRC PVGIS 5 user manual](https://joint-research-centre.ec.europa.eu/photovoltaic-geographical-information-system-pvgis/using-pvgis-5/pvgis-5-user-manual_en) publishes a [PVGIS 5.3 default irradiance-source coverage figure](https://joint-research-centre.ec.europa.eu/sites/default/files/2024-09/PVGIS_53_DB_Coverage.png). Its table lists SARAH3 and PVGIS-ERA5 source periods as 2005–2023 and describes the latter as the default where satellite data are unavailable. The manual says these default databases are also used by the TMY tool. The figure itself labels the yellow region **ERA5LP**; the [JRC status report](https://publications.jrc.ec.europa.eu/repository/bitstream/JRC141263/JRC141263_01.pdf) defines this as ERA5LandPlus, a combination of ERA5-Land and upsampled ERA5 near coasts. The figure distinguishes SARAH3, ERA5LP and a coastal buffer; it is provider-authored context, not a vector footprint derived from the London probe.

When PVGIS TMY is selected, the official JRC figure replaces the point-only canvas as the main map. The linked image is displayed across the available width with its original 5615 × 2119 proportions and no crop or traced boundary; this preserves the transatlantic extent shown by JRC. London is listed separately as the sole exact saved PVGIS v5_3 TMY confirmation. The 2005–2023 dates describe a TMY source/reference period, not a sequence of available actual-year outputs. The figure does not prove that any arbitrary coordinate will return a TMY, which source JRC will select there, hourly completeness, or EPW fitness. This distinction also applies to future shared-service eligibility decisions.
