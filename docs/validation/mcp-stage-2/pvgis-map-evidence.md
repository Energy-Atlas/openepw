# PVGIS v5_3 TMY map context

Reviewed 2026-09-24 for the local multi-product availability map on `feature/data-avail`. This is a bounded documentation follow-up. No Stage 1 collection was rerun, and no new TMY request or hourly data was acquired.

The [JRC PVGIS 5 user manual](https://joint-research-centre.ec.europa.eu/photovoltaic-geographical-information-system-pvgis/using-pvgis-5/pvgis-5-user-manual_en) publishes a [PVGIS 5.3 default irradiance-source coverage figure](https://joint-research-centre.ec.europa.eu/sites/default/files/2024-09/PVGIS_53_DB_Coverage.png). Its table lists SARAH3 and PVGIS-ERA5 source periods as 2005–2023 and describes the latter as the default where satellite data are unavailable. The manual says these default databases are also used by the TMY tool. The figure itself labels the yellow region **ERA5LP**; the [JRC status report](https://publications.jrc.ec.europa.eu/repository/bitstream/JRC141263/JRC141263_01.pdf) defines this as ERA5LandPlus, a combination of ERA5-Land and upsampled ERA5 near coasts. The figure distinguishes SARAH3, ERA5LP and a coastal buffer; it is provider-authored context, not a vector footprint derived from the London probe.

When PVGIS TMY is selected, the interactive map draws a coarse SARAH3 envelope as an opaque blue polygon clipped to the map's land geometry. The polygon extends across eastern South America, Europe and Africa at the reference map's geographic scale. Its 21 manually selected longitude/latitude vertices approximate the outer transition from JRC's green SARAH3 to yellow ERA5LP land regions; the coast buffer, islands and fine boundary details are unresolved. The white London marker is the sole exact saved PVGIS v5_3 TMY confirmation. The unaltered JRC figure remains below the interactive map for comparison, displayed with its original 5615 × 2119 proportions.

For a scale check, the JRC figure's labeled longitude/latitude grid was registered approximately at 16 image pixels per degree, with 0° near pixel `(2808, 1180)`. Sampling solid green and yellow pixels on a 16-pixel grid in the relevant map area, the envelope included 4,694 of 4,716 green samples and excluded 5,291 of 5,342 yellow samples. This is a visual approximation check against the published image, not a georeferenced provider polygon or per-cell validation. The documented SARAH3 dataset extent is 65°W–65°E, 65°N–60°S in the [JRC PVGIS 5.3 dataset update](https://joint-research-centre.ec.europa.eu/document/download/aa763480-b092-48af-a7f8-42913b43d305_en?filename=Report_2024_PVGIS_5.3_Datasets_Update.pdf); the rendered land envelope is narrower where the source figure is yellow or contains no land.

The 2005–2023 dates describe a TMY source/reference period, not a sequence of available actual-year outputs. Neither the figure nor the approximate polygon proves that any arbitrary coordinate will return a TMY, which source JRC will select there, hourly completeness, or EPW fitness. This distinction also applies to future shared-service eligibility decisions.
