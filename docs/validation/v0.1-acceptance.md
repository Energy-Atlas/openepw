Reproduce live checks from the repository root after explicit local configuration:

```powershell
$env:OPENEPW_RUN_LIVE='1'
$env:OPENEPW_RUN_CDS='1'
$env:OPENEPW_RUN_CLIMATE='1'
python -m pytest tests/integration -q
```

Tests explicitly load ignored `.env` only for credentialed providers. Do not turn
live checks on in ordinary CI. Current local caches reduce repeat transfers; CDS
can still submit/poll before reusing a raw body. Credentials and signed retrieval
URLs are not included in committed evidence. Raw logs and bodies remain ignored.

## Review and scientific limits

Independent review findings were fixed and regression-tested: plan/cache path
validation, approved climate stores, byte limits, Windows filenames, Land monthly
boundaries, missing-data aggregation and baseline lineage. Additional checks cover
truncated/changed archive ranges, future scenario consistency, local signal
contracts, calendar preservation, ensemble progress and completed-item recovery.

Analytical tests include identity/+2°C morphing, DTR zero handling, solar scaling,
360-day monthly weighting, medoid and hot/cold shock ranking. Fixture checks cover
normalization, radiation accumulation, EPW fields, time boundaries and provenance.
These tests do not constitute independent climatological calibration or validation
of energy-model performance. No EnergyPlus executable was found on PATH, so no
EnergyPlus consumption/simulation check was run. `simulation_ready` remains false.
